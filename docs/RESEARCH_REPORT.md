# Beyond Lexical Relevance: Evaluating Neural Retrieval, Graph Representation Learning and Context-Aware Ranking for Scientific Information Discovery

## Abstract

This report will compare lexical, neural, graph-based, and context-aware ranking
methods for scientific discovery. No experimental findings are reported yet.

## Research questions

1. How much does scientific dense retrieval improve over BM25 on held-out
   scientific search benchmarks?
2. Do graph-derived features improve relevance after controlling for lexical and
   semantic scores without leaking evaluation edges?
3. Does learned ranking improve NDCG and MRR over a fixed hybrid baseline?
