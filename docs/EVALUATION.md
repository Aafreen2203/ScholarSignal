# Evaluation

There is no labelled query and relevance-judgment set yet. We therefore do not
record retrieval latency or report precision, recall, MAP, MRR, nDCG, or
comparative model gains.

The next evaluation work must create a versioned query/document/judgment set,
document its sampling and split, and keep it separate from the OpenAlex
application corpus. Only then should retrieval relevance metrics be recorded.
